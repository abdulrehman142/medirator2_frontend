# Medirator 2.0 — Frontend

React + Vite + Tailwind UI for the Medirator hospital knowledge assistant.

## Setup

```bash
npm install
cp .env.example .env
# VITE_API_URL=https://your-backend-url
# VITE_GOOGLE_CLIENT_ID=<same as backend GOOGLE_CLIENT_ID>
npm run dev
```

## Env

| Variable | Purpose |
|----------|---------|
| `VITE_API_URL` | Backend base URL |
| `VITE_GOOGLE_CLIENT_ID` | Google OAuth web client ID |

Backend companion: https://github.com/abdulrehman142/medirator2_backend
